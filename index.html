SERVICE FLOW

使用流程

APK 分析與 IoT 管理為兩個獨立服務流程，使用者可依需求選擇對應功能，再分別完成檢測與管理。

進入 APK 分析系統 進入 IoT 管理系統
APK

APK 分析流程

  1. 進入服務選擇 APK 安全分析功能。
  2. 上傳 APK建立分析樣本並啟動安全檢測。
  3. 查看風險結果檢視權限、敏感 API 與可疑行為。
  4. 輸出分析報告下載與分享 App 端安全報告。
IoT

IoT 管理流程

  1. 進入服務選擇 IoT 韌體與裝置管理功能。
  2. 查看韌體版本確認版本、Hash、簽章與 OTA 更新狀態。
  3. 查看裝置連線掌握在線、離線與最後同步時間。
  4. 形成狀態摘要整理成 IoT 裝置端安全管理摘要。
