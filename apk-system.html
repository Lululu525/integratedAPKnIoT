權限風險檢測

檢查 App 是否要求位置、相機、麥克風、簡訊、聯絡人等高敏感權限。

敏感 API 掃描

整理 App 呼叫的敏感 API，協助判斷是否存在潛在安全風險。

可疑行為分析

檢視動態載入、反射、命令執行與 WebView 相關風險行為。

報告輸出

將分析結果彙整為摘要，方便團隊後續討論與修正。
