ABOUT APIONIX

從 App 到裝置，
用同一個視角理解安全。

Apionix 是面向 IoT 產品團隊的整合式安全展示平台，將 APK 靜態分析、機器學習評估、PDF 報告，以及韌體與裝置狀態整理在清楚一致的介面中。

體驗 APK 分析查看 IoT 系統

WHY APIONIX

資訊不再散落，風險才能被正確理解。

一個 IoT 產品同時包含手機 App、韌體、雲端服務與實體裝置。平台把不同來源的資訊放回產品生命週期，協助團隊先理解，再決定處理順序。

01

App 端風險

分析權限、元件暴露、Intent Filter、敏感 API 與反向工程證據，輸出可追溯的 findings。

02

裝置端狀態

整理韌體版本、OTA 更新、簽章驗證、裝置上線狀態與最後同步時間。

03

清楚的報告

將技術結果轉為統一層級、表格與圖表，方便開發人員、管理者與評審共同閱讀。

ANALYSIS MODEL

兩種分析，各自回答不同問題。

STATIC ANALYSIS

靜態規則與證據

回答「實際找到哪些風險？」依據 manifest、permission、component 與 evidence 產生 Static Risk Score 和可解釋 findings。

  • 具體問題與修正建議
  • Low／Medium／High 統計
  • 四頁 PDF 報告

MACHINE LEARNING

模型相似性評估

回答「整支 APK 的特徵較接近哪一類樣本？」ML 結果與靜態分數分開呈現，不直接相加，也不假裝是單一元件的證據。

  • 獨立模型狀態與版本
  • Probability／classification
  • 缺少 artifact 時誠實標示

SYSTEM ARCHITECTURE

保留成熟架構，讓各模組獨立演進。

FastAPI 負責 API，Celery 與 Redis 處理背景工作，SQLite 保存 metadata；AI-model 負責分析，React 負責操作介面，ReportLab 產出報告。
