SERVICE WORKFLOW

從檔案上傳到可分享報告，
每一步都有清楚狀態。

依需求選擇 APK 安全分析或 IoT 裝置管理。兩條流程彼此獨立，最後回到同一個產品安全視圖。

APK 分析流程IoT 管理流程
APK

APK 安全分析

適合開發、測試或上線前檢查 Android 安裝檔。

進入分析系統
01

上傳檔案

選擇 APK，系統建立 sample ID 並保存原始檔名。

輸入：Android APK
02

啟動分析

背景工作執行靜態解析、規則檢查及可用的 ML artifact。

狀態：queued／running
03

查看結果

檢視靜態風險分數、findings、權限與 ML 評估。

狀態：finished／failed
04

下載報告

從 Result 右上角下載四頁安全分析 PDF。

輸出：security_report.pdf
結果怎麼看？

Static Analysis Score 來自規則與 evidence；Machine Learning Score／Probability 是模型輸出。兩者分開解讀，不直接相加。

IoT

IoT 韌體與裝置管理

適合檢視裝置部署、韌體版本與 OTA 狀態。

進入 IoT 系統
01

選擇裝置

從產品或裝置清單進入管理視圖。

資訊：Device ID
02

確認韌體

查看版本、Build、Hash 與簽章驗證狀態。

資訊：Firmware
03

追蹤 OTA

掌握更新進度、成功狀態與部署結果。

資訊：OTA status
04

查看連線

確認 Online／Offline、最後同步與裝置健康狀態。

資訊：Connectivity

清楚的流程，讓技術結果更容易被理解與採取行動。
